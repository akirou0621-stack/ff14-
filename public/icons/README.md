# ジョブアイコンの置き場所

ここに画像を入れるだけで、カードのジョブアイコンが自動で差し替わります。
コードを触る必要はありません。

**画面の絵つきの手順はこちら → https://ff14.vercel.app/icon-guide.html**

## 入れ方

1. このフォルダ（`public/icons`）を開いた状態で「Add file」→「Upload files」
2. 画像をドラッグして「Commit changes」
3. 1〜2分でサイトに反映されます

同じ名前のファイルを入れ直せば、上書きされます。

## 画像のルール

- **ファイル名は下の表の「ファイル名」にする**（小文字・半角）
- 形式は **PNG**
- **背景は透明**にする
- 大きさは **正方形・512×512 くらい**がおすすめ（大きすぎると表示が遅くなります）
- アイコンはマスいっぱいに表示されます
