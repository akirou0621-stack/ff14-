ジョブアイコンの入れ方

GitHubのフォルダに画像を入れるだけで、カードのアイコンが入れ替わります。パソコンでの手順です。赤い枠のところを順番に押してください。

0

はじめに一度だけ：招待を受ける

GitHubから「招待（invitation）」のメールが届いています。メールを開いて Accept invitation を押してください。これを押していないと、アップロードのボタンが出てきません。

メールが見つからないときは、GitHubにログインして右上のベルのマーク（お知らせ）を見てください。

1

このリンクを開く

カードジェネレータの置き場所（リポジトリ）https://github.com/akirou0621-stack/ff14-

開いたら、右上にGitHubの自分のアイコンが出ているか（ログインしているか）確認してください。

2

「public」フォルダを押す

ファイルの一覧の中から、青いフォルダのマークの public を押します。

ff14-Add file ▾<> Code ▾
app…
lib…
publicここを押す
README.md
package.json
3

「icons」フォルダを押す

中に2つフォルダがあります。icons のほうを押してください。jobs ではありません。

ff14-/public/
iconsここを押す
jobsこっちは押さない
4

「Add file」→「Upload files」

まず、画面の上の場所の表示が ff14- / public / icons / になっているか確認します。なっていたら、右上の Add file を押して、出てきたメニューの Upload files を押します。

ff14-/public/icons/Add file ▾①
Create new file
Upload files ②
README.md
pld.png
5

画像をドラッグして入れる

点線の四角の中に、パソコンの画像ファイルをマウスでつかんで持ってきて、離します。choose your files を押して、画像を選ぶこともできます。何枚かまとめて入れても大丈夫です。

ff14-/public/icons/
Drag files here to add them to your repository Or choose your files
🖼 war.png ここに入れる
war.png← 入れた画像が並ぶ

下に並んだ名前が war.png のようにファイル名だけになっていればOKです。名前は下の一覧どおりにしてください。

6

「Commit changes」を押す

画面をいちばん下までスクロールして、緑の Commit changes を押します。文字の欄は何も書かなくて大丈夫です。

Commit changes
Add files via upload
Add an optional extended description…
Commit changes ここを押す
7

1〜2分待って、サイトで確認

自動でサイトが更新されます。少し待ってから開くと、アイコンが入れ替わっています。

カードジェネレータhttps://ff14.vercel.app

変わっていないときは、もう少し待ってからページを再読み込み（F5、Macは ⌘+R）してください。

同じ名前の画像をもう一度入れれば、上書きされます。描き直したときも同じ手順でOKです。

!

画像のきまり

  • 形式は PNG（ファイル名の最後が .png）
  • 背景は透明にする
  • 正方形で、512×512 くらいの大きさがおすすめ
  • ファイル名は半角の小文字で、下の一覧どおりにする

うまくいかないとき

「Add file」が出てこない
手順0の招待を受けていないか、GitHubにログインしていません。

アイコンが変わらない
ファイル名が一覧と違うかもしれません（大文字が入っている、.PNG になっている、など）。GitHubの icons フォルダで名前を確認してください。

違う場所に入れてしまった
そのままで大丈夫です。お願いした人に知らせてもらえれば直します。
