# FFXIV Profile Card

ロドストからジョブレベルを読み込んで、FF14の自己紹介カードを作れるジェネレータです。

## できること

- ロドストのキャラページURL（またはキャラID）から、名前・ワールド・DC・FC・全ジョブのレベルを読み込み
  - 未解放のジョブは空欄、カンストは金色で表示
  - ロドストの全身画像と顔アイコンも、空いている画像枠に自動で入る
- 手書き風ジョブアイコン付きのジョブ表（戦闘21ジョブ＋青魔・魔獣使い・クラフター・ギャザラー）
- 平日・休日のプレイ時間を24マスでなぞって塗る
- 背景・キャラ画像・丸アイコン3枚のアップロード、キャラ画像の拡大と位置調整
- 入力内容はブラウザに自動保存
- PNGで書き出し（1024×1156 の2倍サイズ）

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `app/page.tsx` | 編集画面とカードの見た目 |
| `app/globals.css` | デザイン（カードは原寸 1024×1156 で組んである） |
| `lib/jobs.ts` | ジョブの一覧・並び順・ロドスト上の表記・レベル上限 |
| `lib/lodestone.ts` | ロドストのページから情報を抜き出す処理 |
| `app/api/lodestone/route.ts` | ブラウザの代わりにロドストを読みに行くサーバー処理 |
| `app/api/image/route.ts` | ロドストの画像を中継（PNG書き出しで止められないように） |
| `public/jobs/*.png` | ジョブアイコン |

## よくある直し方

- **ロドストから読めなくなった** → ロドストのデザインが変わった可能性。`lib/lodestone.ts` の `SELECTORS` を新しいクラス名に直す
- **レベル上限が上がった** → `lib/jobs.ts` の `DEFAULT_LEVEL_CAP` を変える
- **新ジョブが来た** → `lib/jobs.ts` に1行追加して、`public/jobs/` にアイコン画像（ID名.png）を置く

## 手元で動かす

```bash
npm install
npm run dev
```

http://localhost:3000 を開く。

## 公開（Vercel）

サーバー処理（ロドスト読み込み）があるので、GitHub Pages ではなく Vercel で公開します。

1. https://vercel.com に GitHub アカウントでログイン
2. 「Add New… → Project」でこのリポジトリを選んで「Deploy」
3. 以降は GitHub に push するたびに自動で更新されます
